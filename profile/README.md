# Neo Backup - App Data Copies on a Rooted Phone

## At a Glance

A stock phone can back up some data to a cloud account and can let individual apps export files. Neo Backup is the local, per-app copy you run when you have root and you want APK plus data for apps you choose. Restores are most reliable onto the same app version. A newer app may refuse an old data directory. That is the app, not a bug in the backup list.

- Root already present on a phone you own
- A destination folder you can copy to a computer
- Apps selected one by one or from a list you have read
- Restore tested before you wipe the only phone
- No coverage of every system setting and every account token

Some apps detect backups, encrypt data, or bind it to a device. Neo Backup can still copy the files and the app can still reject them. Treat a restore of a banking or authenticator app as uncertain and keep the original enrollment.

## What a Job Includes

| Piece | Expectation |
|---|---|
| APK | Enough to reinstall that version |
| Data | Private files root could read |
| External data | Only if you included it |
| System settings | Not a full ROM backup |
| Cloud passwords | Not included just because the app was |

1. Pick a destination with room.
2. Back up one unimportant app and restore it as a test.
3. Then back up the set you care about.
4. Copy that folder off the phone.
5. Restore onto a matching version if you can.
6. Sign in again anywhere the app rejects the copied data.

## Fits

Rooted phones you are about to wipe or migrate. A poor fit for a locked bootloader with no root. A poor fit as the only copy of photos that live in a normal folder. Copy those with a file manager. A poor fit for a full firmware image.

## Fixes

The app says it needs root. You do not have a working root method. Neo Backup cannot invent one.
A restore installs and the data is empty. The app rejected the directory or you did not include data.
The backup is on internal storage and you formatted. It is gone. That is why the copy belongs on a computer.
An app crashes after restore. Install the old version from the saved APK, or skip the data and sign in fresh.
You needed a partition image. Use a recovery backup or a PC tool, not an app-data copier.

## Test One Restore Before the Wipe

Neo Backup needs root on a phone you own. Without it, other apps' private data is not yours to read, and the program will not pretend. Back up one unimportant app, restore it, and only then select the set you care about. Copy that folder to a computer. A backup that stays on the phone you are about to format is gone with the format.

Restores like the same app version. A newer app can reject an old data directory. Banking and authenticator apps may refuse a copied data folder even when the files restored. Keep their own enrollment. Photos in a normal folder are a file copy, not this tool. A partition image is a recovery backup, not an app-data job.

- Root already working
- Destination with room
- One restore tested
- Folder copied off the phone
- APK kept so you can reinstall that version
- Cloud tokens not assumed
- System settings not expected inside an app backup

| Restore result | What it means |
|---|---|
| App opens with data | The test worked |
| App opens empty | Data was skipped or rejected |
| Crash | Try the saved APK, or sign in fresh |
| Backup missing | It lived on the storage you formatted |

Write the destination path down. "Internal storage" is not a path you will find after a wipe.
